# M1 응답 화면 시안 · 2026-09-13

사후 개선. 사용자 요청에 따라 화면디자인을 먼저 수정했다. 사용자 리뷰 대기, 사용성 효과와 포트폴리오 수록 미정.

## 화면과 판단
- 최초 응답: 회색 공통 트레이 대신 개별 선택 면. 제목과 짧은 결과 설명을 분리했다. 선택은 기존 파란 테두리·옅은 파란 면으로 통일하며 모바일에서 카드 전체 너비를 사용한다.
- 제출 전 확인: 조정 의향만 묻던 모달을 전체 날짜별 응답 요약으로 변경했다. 조정 검토가 참석 약속이 아님을 요약 아래 표시한다. 모바일은 하단 시트.
- 응답 완료: 큰 건수 요약을 날짜·시간·응답 목록으로 대체하고 ‘시간 확정 전’을 표시했다. 확인과 완료가 같은 ResponseAnswerList를 사용한다.
- 무드보드 005·011의 흰 패널, 얕은 깊이, 옅은 파란 선택 면을 기존 토큰 안에서 적용했다. 새 팔레트나 도메인 모델 변경은 없다.

## 대안과 남은 판단
즉시 제출은 빠르지만 의향과 약속의 차이를 놓칠 수 있다. 이번 시안은 모든 응답에 확인 단계를 둔다. 실제 이해 향상은 미검증이며 단계 추가 비용도 평가해야 한다. 선택 카드의 보조 설명 반복과 전체 세로 길이도 다음 리뷰 대상이다. 전체 시간 범위 입력 화면은 이번 수정 범위가 아니다.

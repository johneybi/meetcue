# M2 요청 이후 상태 · 2026-09-14

화면디자인 우선 사후 개선. 사용자 승인, 시안 적용·리뷰 대기. 실제 발송이나 서버 연결 없음.

- 참석자 요청: 후보 시간, 조정이 필요한 내 일정, 동의 범위, 선택과 전송 순서. 반복 선택 설명 제거, 선택한 답에 맞춘 버튼 문구. 16px 모서리·얕은 그림자·명시적인 선택 면 유지.
- 거절 후: 종료된 경로와 유지되는 다른 후보 응답을 상단 안내로 구분.
- 일부 동의: 남은 당사자, 동의 수, 확정 전제 조건을 상단에 묶고 행의 동의/대기를 구분. 비활성 버튼에 기다리는 인원 표시.
- 화면 전환 시 상단으로 이동하여 제목부터 읽도록 수정.

대안: 상태를 후보 카드 안에만 두면 비교 후 진행 상태를 놓칠 수 있어 상단 안내를 추가했다. 제목·후보 카드와의 반복 및 상단 세로 길이는 남은 리뷰 대상이다. 새 도메인 상태는 추가하지 않았다.

브라우저: 민수 변경 불가 → 주최자 복귀 → 수진·서연 요청 → 수진만 동의 → 서연 대기 흐름 확인. 최종 확정 버튼 비활성 확인. 빌드·린트 통과. 모바일 시각 검수는 이전 viewport 문제로 아직 미완료이며 사용자 연구는 하지 않았다.

# M1 확인·완료 화면 간격 정리

2026-09-14 사후 개선. 사용자 요청: 디자인 우선 작업을 이어가며 목적별 커밋과 GitHub 반영.

- 확인: 480px 패널, 24px 좌우 패딩(모바일20px), 제목25px, 설명13px. 날짜와 응답보다 시간18px을 먼저 읽도록 조정. 행 패딩16px, 구역 간격24px.
- 완료: 최초 응답과 같은 28/25px 제목, 16px 모서리, 얕은 그림자. 큰 완료 아이콘을40px로 줄임. 전달한 응답과 다음 행동 안내를 분리하고 중복 설명 제거.
- 대안: 안내를 요약 카드 안에 유지하면 묶음은 작지만 과거 응답과 미래 행동이 섞인다. 이번에는 바깥에 별도 배치하고 세로 길이를 감수한다.
- 상태: 시안 적용·브라우저 검수. 실제 사용자 이해 검증·포트폴리오 수록 미정. 다음은 M2 대표 화면 디자인이며 개발 연결은 후순위.
- 검수: 빌드·린트 통과. 혼합 응답을 제출하고 완료 목록을 읽은 후 수정·확인으로 복귀. 모바일390×844 가로 넘침 없음.

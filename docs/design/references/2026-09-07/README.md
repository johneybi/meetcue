## 이번 구현의 표현

- 회백색 바탕 위에 흰 작업 면을 올린다. 글자 대비는 이미지보다 명확하게 유지한다.
- 주요 버튼은 파란 세로 그라데이션과 얕은 아래 그림자. 작은 헤더 버튼도 같은 재질을 쓴다.
- 일반 선택지는 흰색에서 옅은 회색으로, 선택한 항목은 옅은 파란색으로 바뀐다. 테두리·체크·라디오 상태를 함께 사용한다.
- 그림자는 패널의 구분과 조작 가능성을 돕는 정도로 제한한다. 모든 정보 조각을 별도 카드로 만들지는 않는다.
- 기존 선택 표시 이동·응답 개수 갱신·전환 모션을 유지하고, 공통 버튼에는 짧은 눌림 피드백을 적용했다. `prefers-reduced-motion`에서는 이동을 줄인다.
- 사진 배경, 유리 외곽 프레임, 장식용 차트는 현재 과업에 필요하지 않아 옮기지 않았다.

공통 색·표면·그림자는 `src/styles/meetcue-theme.css`, 버튼·입력·선택 상태는 `src/components/ui/primitives.css`가 담당한다. 크기별 버튼 변형에는 크기만 남기고, 만들기·응답·결과 화면에서 공통 버튼 재질을 덮어쓰던 규칙을 정리했다.

## 후속 조정: 표면의 역할

사용자가 ‘플랫한 배경과 뉴모피즘에 가까운 요소가 섞여 애매하다’고 지적한 뒤, [표면의 역할을 정리하는 방향](../../../research/surface-intent/README.md)을 승인했다. 현재 구현은 일반 패널의 내부 하이라이트·넓은 그림자를 줄이고 흰 면과 경계로 정보를 묶는다. 부드러운 입체 표현은 주요 버튼·입력과 일시적인 오버레이에 집중하며, 선택은 파란 면과 테두리로 표현한다. 위 이미지 해석은 초기 적용 기록이며 이 후속 판단과 함께 참고한다.

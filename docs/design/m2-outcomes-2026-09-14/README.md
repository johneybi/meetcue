# M2 최종 확정·새 제안·종료 · 2026-09-14

화면 시안 적용·사용자 리뷰 대기. 사후 개선이며 실제 발송이나 캘린더 변경 없음.

- 전원 동의와 주최자 확정을 구분. 전원 동의 시 중복 상태 박스를 숨기고 아직 확정 전임을 안내.
- 참석자 확정 화면은 이전의 '옮기지 마세요' 안내를 상태에 맞게 바꾸고 직접 옮길 일정 표시. 거절·취소된 요청은 옮길 필요 없다고 안내.
- 종료 화면은 확정 시간 없음, 기존 응답 보존, 요청 종료, 일정 유지로 구성.
- 새 시간 제안의 기존 응답 보존/새 후보 재확인 문구 정리. 날짜·시간 데스크톱 2열, 모바일1열.
- 대안: 모든 상태에 같은 대기 안내를 유지하면 일관돼 보이지만 실제로 행동을 잘못 유도할 수 있어 상태별 설명을 선택. 종료 제목의 중복은 기록 요약으로 수정.
- 한계: 여전히 가상 단일 사례이고 사용자 이해·효과 미검증. 상태 안내의 밀도와 후보가 많은 경우의 스크롤은 사용자 리뷰 대상. 포트폴리오 수록 미정.

검수: 수진·서연 동의→주최자 확정→수진 확정 안내 데스크톱 확인. 모바일390×844에서 최초 비교→민수 거절→수진 거절→후보 소진→새 시간 입력창→확정 없는 종료 확인. 종료 문서 가로 넘침 없음. 실제 새 후보 제출은 이번 검수에 포함하지 않았고 기존 동작 유지. 모바일 전원동의·확정 장면은 이번에 별도 캡처하지 않음. 빌드·린트 통과.

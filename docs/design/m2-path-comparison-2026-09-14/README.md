# M2 복구 경로 비교 · 2026-09-14

사후 개선, 화면 시안 적용·사용자 리뷰 대기. 포트폴리오 수록 미정.

문제: 기존 시안은 숫자, 날짜, 참석자 상태를 나열해 주최자가 조건을 조합해서 읽어야 했다. 사용자에게 검증한 문제가 아니라 에이전트의 화면 해석이다.

- 시간 → 필요한 사람의 동의 → 인원·일정 건수 → 구체적인 일정 → 유지되는 응답 → 요청 순으로 구성.
- 날짜 배지 중복 제거, 제목30px/모바일25px, 시간26px, 조건문18px. 카드 패딩24px/모바일20px, 간격16px. 흰 표면·얕은 그림자·파란 상태 강조 유지.
- 두 경로의 버튼과 기존 응답 정보를 같은 높이에 배치. 1명 동의 후보를 추천하거나 사회적 비용이 더 낮다고 주장하지 않음.
- 닫힌 후보는 아래의 간결한 목록으로 유지. 새 시간 제안·종료 경로 보존.
- 대안: 숫자를 크게 강조하는 비교표는 간결하지만 1명을 최적으로 받아들이게 할 수 있어 이름과 필요한 동의를 문장으로 제시했다. 같은 이름이 상세에도 반복되는 점, 후보가 많을 때의 긴 스크롤은 후속 검토 사항.
- 기존 상태 계산·서버 연결은 변경하지 않음. 미확인·변경 건수 미공유 상태를 유지한다.

검수: 빌드·린트 통과, 초기 비교와 민수 요청 확인창의 후보·대상 일치 확인. 실제 발송 없음. 모바일 CSS 작성했으나 브라우저 viewport 설정이 적용되지 않아 모바일 시각 검수는 미완료.

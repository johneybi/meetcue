# 공통 배경의 화면별 점검 — 2026-09-07

상단 흰색에서 하단의 옅은 회색으로 이어지는 배경이 홈 이외의 화면에서도 정보 위계를 유지하는지 확인했다. 로컬 앱의 실제 화면을 먼저 캡처하고, 남은 화면별 그림자 규칙을 조정했다. 이 기록은 점검 당시의 판단이며 고정된 디자인 규칙은 아니다.

## 검증 범위와 한계

- 데스크톱과 390×844 모바일 뷰포트 설정에서 주요 화면을 비교했다. 모바일 캡처의 콘텐츠 폭은 스크롤바를 제외해 약 375px다.
- 확인은 화면 위계, 면과 그림자의 일관성, 보이는 상태 구분에 집중했다. 모든 작성 단계·오류·빈 상태를 검증한 것은 아니다.
- 회의 확정, 응답 제출, 기준 적용을 새로 실행하지 않았다. 확정 화면은 이미 확정된 회의를 사용했다.
- 색상 외 상태 문자와 컨트롤 이름을 확인했지만 전체 키보드·스크린리더·명도 대비 감사를 수행한 것은 아니다.
- `npm run build`, `npm run lint`, `git diff --check` 통과. 변경은 CSS에 한정된다.

## 별도 확인이 필요한 동작

제품 리뷰 회의 결과에는 ‘필수 3명 · 최소 4명’이 표시되지만 참석 기준 수정 진입 시에는 ‘필수 참석자만 오면 진행’이 선택되어 있었다. 표시된 초기 선택과 기존 조건의 일치 여부는 기능 점검 대상으로 남긴다. 이번 시각 점검에서는 기준을 적용하지 않았다.

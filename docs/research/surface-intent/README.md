# 표면 표현의 의도 점검 · 2026-09-07

1. 홈 화면 — 정보 구획은 읽히지만 입체감의 역할이 불명확함.

이번에 캡처한 `01-home.png`를 기준으로 한 시각 리뷰다. 상단 요약과 조율 중 회의는 흰색의 부풀어 오른 면으로 보이고, 작성 중과 확정된 일정은 배경에 직접 놓여 있다. 큰 요약 면과 작은 작업 항목의 상대적 중요도도 다시 정리할 여지가 있다. 작은 회색 보조 문구와 얇은 경계는 시각적으로 약해 보이며, 접근성 수치나 키보드 조작은 이번 리뷰에서 검사하지 않았다.

추천 방향: 차분한 작업 공간을 바탕으로, 표면의 높이에 역할을 부여한다. 페이지 배경은 옅은 중성 회색, 업무 묶음은 선명한 흰 면과 얇은 경계, 상시 패널의 그림자는 거의 없거나 짧게, 버튼과 일시적인 팝오버에만 더 높은 깊이를 준다. 입력은 안으로 들어간 면, 선택은 파란 경계와 체크, 확정은 의미 있는 상태색으로 구별한다.

홈에서는 요약 숫자를 더 작은 안내 영역으로 낮추고, 응답하거나 결정할 회의를 중심에 둔다. 레퍼런스의 부드러운 빛은 유지하되 모든 카드가 같은 물체처럼 부풀어 보이지 않게 한다. 모션은 누름·선택·결정에 대한 피드백을 따른다. 배경에 큰 색 번짐을 추가하는 것만으로 이 문제를 해결하려 하지 않는다.

이 문서는 개선 제안이며 코드 변경을 포함하지 않는다.

## 적용 결과

위 제안을 사용자 승인 후 구현했다.

- [홈 데스크톱](02-home-after-desktop.png), [홈 모바일](03-home-after-mobile.png), [회의 결과](04-results-after.png).
- 상단의 요약 카드와 큰 숫자를 작은 현황 링크로 바꾸고, 응답·조율·작성 중 항목을 하나의 흰 작업 영역으로 묶었다. 확정 일정은 별도 영역으로 같은 표면 규칙을 따른다.
- 배경에는 560px에 걸친 미세한 중성 명암을 사용한다. 일반 패널은 흰 단색과 짧은 1px 그림자, 얇은 경계를 쓴다. 내부 하이라이트와 넓게 퍼지는 패널 그림자는 제거했다.
- 선택 면은 옅은 파란색과 선으로 표시한다. 버튼의 그라데이션·얕은 입체감·눌림 피드백, 입력의 얕은 안쪽 그림자를 유지했다.
- 홈에서 ‘이어서 만들기’를 명시하고 모바일에서도 실제 작업 링크가 보이게 했다. 링크처럼 보이는 문구는 기존 전체 행 버튼의 일부이며 중첩 버튼은 만들지 않았다.
- 390px 모바일, 820px 태블릿, 기본 데스크톱 화면을 확인했다. 320px에서도 홈 가로 넘침이 없었다. 홈 → 회의 결과 → 로고로 홈 복귀를 확인했다.
- 빌드·린트·기존 도메인 테스트 44개 및 diff 공백 검사 통과. 데이터·판단 로직은 변경하지 않았다.

### 배경 명암 방향 조정

상단의 회색이 비활성 영역처럼 보인다는 후속 피드백을 반영했다. 현재 배경은 상단 흰색 → 240px의 거의 흰색 → 620px의 옅은 회색으로 내려간다. 현황 링크의 글자와 0건 숫자도 대비를 높였다. 앞선 캡처는 조정 전 기록이다. 조정 후 홈 화면을 브라우저에서 확인하고 빌드를 검증했다.

## 새 스토리 최소 기준

- 실제 제품 컴포넌트 또는 고정된 도메인 fixture를 사용합니다.
- 기본 상태와 함께 해당 컴포넌트에 의미 있는 선택·비활성·빈 상태를 다룹니다.
- 접근 가능한 이름과 키보드 조작 여부를 Accessibility 패널과 직접 조작으로 확인합니다.
- 390px와 데스크톱에서 정보 손실이나 수평 넘침이 없는지 확인합니다.
- 미지원 상태는 임시 UI로 꾸미지 않고 이 문서의 남은 경계에 기록합니다.
- `check`, `lint`, `build-storybook`을 통과합니다.

# Product state model

MeetCue는 “가능한 시간” 하나만 표시하지 않습니다. 응답이 덜 모인 상태와, 알려진 충돌 때문에 조건 변경 동의가 필요한 상태를 분리합니다.

## 응답 의미

- `available`: 해당 후보에 참석 가능
- `adjustment_intent`: 기존 일정 조정을 검토할 의향이 있음. 동의가 아님
- `adjustable` / `adjustment_commit`: 이전 흐름에서 실제 변경을 약속한 기록
- `unavailable`: 해당 후보에 참석 불가
- unanswered: 아직 모름. 불가로 추정하지 않음

스토리는 가능하면 이 상태를 임의 문자열로 주입하지 않고, 고정된 가상 회의 fixture와 도메인 계산 결과에서 만듭니다. 그래야 화면 표현뿐 아니라 계산과 UI 사이의 계약을 함께 검토할 수 있습니다.
